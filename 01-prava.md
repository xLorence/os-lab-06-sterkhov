# Отчет по заданию 2 (umask)

**Вывод прав при разных масках:**
* Со стандартной маской (`0022`): файл получил права `644`, каталог — `755`.
* Со строгой маской (`0077`): файл получил права `600`, каталог — `700`.

**Расчет прав:**
Система вычисляет итоговые права, "вычитая" значение маски из базовых прав.
* **Для каталогов** базовые права — `777` (полный доступ для всех). 
  * С маской `022`: `777 - 022 = 755`
  * С маской `077`: `777 - 077 = 700`
* **Для файлов** базовые права — `666` (чтение и запись, без выполнения). 
  * С маской `022`: `666 - 022 = 644`
  * С маской `077`: `666 - 077 = 600` (маска полностью отсекает права у группы и остальных).

**Почему у файлов нет бита x (выполнение), а у каталогов есть:**
Бит `x` на файле делает его исполняемой программой. По умолчанию система не выдает его из соображений безопасности, чтобы случайно не запустить обычный текстовый документ как скрипт. А вот для каталога бит `x` означает право "войти" в него (например, командой `cd`) и получить доступ к содержимому. Без этого бита папка будет бесполезной.

**Зачем на серверах с конфиденциальными данными ставят umask 077:**
Эта маска жестко обрубает любые права для группы и остальных пользователей (оставляя нули). Это значит, что любой новый файл или папка будут доступны только их создателю (владельцу). Это защищает от случайных утечек — даже если админ забудет вручную закрыть доступ к секретному файлу, он изначально будет недоступен для посторонних.
